I want to build a room planner app. 

A birds eye view version of a users room where they can add add things like desks, cabinets, beds, etc.

Core features:
- Create a custom room layout with user-defined dimensions
- Support different room shapes, not just rectangles
- Add and position doors, windows, vents, and electrical outlets with user defined dimensions
- Add furniture using preset options or fully custom dimensions
- Move, rotate, resize, and delete furniture items
- Show everything from a top-down/bird’s-eye view

Future AI/ML feature:
- Add a recommendation system that suggests better furniture placement based on room size, outlets, vents, windows, and doors
- For now, do not build the AI feature fully
- Instead, design the app structure so this feature can be added later

Tech stack requirements:
- Use Next.js (App Router) with React and TypeScript
- Use Tailwind CSS for styling
- Use react-konva for the interactive canvas (drag, resize, rotate furniture and room elements)

Constraints:
- Do NOT add a database, authentication, or any backend
- Do NOT implement saving (no localStorage for now)
- Do NOT add AI features yet
- Keep everything client-side

Focus:
- Build a clean, simple to use UI
- Prioritize smooth drag-and-drop, resizing, and rotation
- Keep the code modular and easy to extend later (for saving and AI)
